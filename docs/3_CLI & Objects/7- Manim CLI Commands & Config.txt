7- Manim CLI Commands & Config

🚀 Manim CLI Commands & Config — Deep Developer Guide

🧠 1. Mental Model (Start Here)
Before commands, understand this:
CLI Command → parse_cli() → args (Namespace)
           → initialize_manim_config()
           → merge + update
           → ONE OBJECT → manim_config
           → used everywhere
👉 Everything in Manim depends on ONE final object:
manim_config

⚙️ 4. CLI → args (Namespace)
Example Command
manimgl logo_intro.py LogoIntro -r 1920x1080 --fps 60 -c black -t
Converted to Python Object
args = Namespace(
    file="logo_intro.py",
    scene_names=["LogoIntro"],
    resolution="1920x1080",
    fps=60,
    color="black",
    transparent=True,
    write_file=False,
)
👉 This object is passed into config system.

🧠 10. Important Concept — Mutation
Inside update functions:
camera_config = config.camera
camera_config.fps = 60
👉 No new object created👉 Same object updated

Visual
config
 └── camera
      ├── fps = 30

camera_config ─────┐
                   ▼
               SAME OBJECT

camera_config.fps = 60

config.camera.fps → 60

🔍 11. Example Flow
Command
manimgl file.py Scene -r 1000x300 --fps 60 -c black -t

    resolution: (1000, 300),
    fps: 60,
    background_color: black,
    background_opacity: 0.0

🧠 13. Key Concepts to Remember
￼
🎯 14. Final Summary
CLI → args
args → config builder
config builder → merge YAML
merge → update functions
update → mutate sections
return → ONE object

🔥 One Line
Manim CLI builds one global config object (manim_config) by merging YAML files and CLI arguments, then mutating each section for runtime use.
