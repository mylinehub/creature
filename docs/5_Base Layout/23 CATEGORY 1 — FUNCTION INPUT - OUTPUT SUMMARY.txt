23 CATEGORY 1 — FUNCTION INPUT / OUTPUT SUMMARY
========================================================

FUNCTION 1 — get_norm
========================================================

CODE
--------------------------------------------------------

def get_norm(vect):
return sum((x**2 for x in vect))**0.5

--------------------------------------------------------
PURPOSE
--------------------------------------------------------

Find vector length / magnitude.

--------------------------------------------------------
INPUT
--------------------------------------------------------

A vector.

Examples:

(3,4)
(1,2,2)
[5,8]
np.array([1,2,3])

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Single number.

Examples:

get_norm((3,4))
→ 5

get_norm((1,2,2))
→ 3

--------------------------------------------------------
MEANING
--------------------------------------------------------

“How long is this directional movement?”

--------------------------------------------------------
MATH
--------------------------------------------------------

sqrt(x²+y²+z²...)

--------------------------------------------------------
USED FOR
--------------------------------------------------------

- vector length
- normalization
- distance
- graphics movement
- tangent length
- projection scaling

========================================================
FUNCTION 2 — normalize
========================================================

CODE
--------------------------------------------------------

def normalize(vect, fall_back=None):
norm = get_norm(vect)
if norm > 0:
return np.array(vect) / norm
elif fall_back is not None:
return np.array(fall_back)
else:
return np.zeros(len(vect))

--------------------------------------------------------
PURPOSE
--------------------------------------------------------

Remove magnitude.
Keep direction.

Creates UNIT VECTOR.

--------------------------------------------------------
INPUT
--------------------------------------------------------

Vector.

Optional fallback vector.

Examples:

(3,4)
(10,0)
(0,0)

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Unit vector.

Examples:

normalize((3,4))
→ (0.6,0.8)

normalize((10,0))
→ (1,0)

--------------------------------------------------------
ZERO VECTOR CASE
--------------------------------------------------------

normalize((0,0))

cannot divide by zero.

So:

- use fallback
OR
- return zero vector

--------------------------------------------------------
MEANING
--------------------------------------------------------

“Keep only direction.”

--------------------------------------------------------
MATH
--------------------------------------------------------

vector / vector_length

--------------------------------------------------------
USED FOR
--------------------------------------------------------

- normals
- movement direction
- lighting
- camera facing
- projection
- rotations
- tangent flow

========================================================
FUNCTION 3 — normalize_along_axis
========================================================

CODE
--------------------------------------------------------

def normalize_along_axis(array, axis):
norms = np.sqrt((array * array).sum(axis))
norms[norms == 0] = 1
return array / norms[:, np.newaxis]

--------------------------------------------------------
PURPOSE
--------------------------------------------------------

Normalize MANY vectors together.

--------------------------------------------------------
INPUT
--------------------------------------------------------

2D NumPy array.

Example:

[
[3,4],
[5,12]
]

axis value.

Usually:

axis=1

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Array of normalized vectors.

Example:

[
[0.6,0.8],
[0.384,0.923]
]

--------------------------------------------------------
MEANING
--------------------------------------------------------

“Normalize entire batch of vectors.”

--------------------------------------------------------
MATH
--------------------------------------------------------

For EACH row:

vector / vector_length

--------------------------------------------------------
IMPORTANT NUMPY IDEAS
--------------------------------------------------------

- broadcasting
- vectorization
- axis
- np.newaxis
- boolean masking

--------------------------------------------------------
USED FOR
--------------------------------------------------------

- graphics pipelines
- thousands of vectors
- point clouds
- normals
- rendering
- GPU-style preprocessing

========================================================
FUNCTION 4 — norm_squared
========================================================

CODE
--------------------------------------------------------

def norm_squared(v):
return sum(x * x for x in v)

--------------------------------------------------------
PURPOSE
--------------------------------------------------------

Compute length²
WITHOUT square root.

--------------------------------------------------------
INPUT
--------------------------------------------------------

Vector.

Examples:

(3,4)
(1,2,2)

--------------------------------------------------------
OUTPUT
--------------------------------------------------------

Single number.

Examples:

norm_squared((3,4))
→ 25

norm_squared((1,2,2))
→ 9

--------------------------------------------------------
MEANING
--------------------------------------------------------

“How large is vector before sqrt?”

--------------------------------------------------------
MATH
--------------------------------------------------------

x²+y²+z²...

--------------------------------------------------------
WHY IMPORTANT
--------------------------------------------------------

sqrt expensive.

Sometimes only comparison needed.

--------------------------------------------------------
USED FOR
--------------------------------------------------------

- nearest neighbor
- collision detection
- graphics optimization
- physics
- fast comparisons
