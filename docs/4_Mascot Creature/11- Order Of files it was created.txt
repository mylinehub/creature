Why render_scene.py moved down
Because it depends on us already having:
scenes
naming choices
logging style
render flow decisions
So it should come later, not early.
Logging plan
Yes, we will keep logging centralized.
one-place control
config/logging_config.py
This will define:
log level
format
enable/disable debug
logger names
shared logger access
core/logger.py
This will expose helper functions like:
get_logger(__name__)
maybe setup/init wrapper
So later files can do:
from core.logger import get_logger
logger = get_logger(__name__)
and then use:
logger.info("...")
logger.error("...")
logger.debug("...")
without repeating setup everywhere.
