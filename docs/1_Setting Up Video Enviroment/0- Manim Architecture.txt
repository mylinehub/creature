7- Manim Architecture

Intro File:


from manimlib import *

class LogoIntro(Scene):
    def construct(self):
        text = Text("MyLineHub")
        self.play(Write(text))
        self.wait()



Above is first file you write. Here TEXT , Scene class which is inherted comes from Manim. This article explains you how Manim is created and how you can utilize it fully
