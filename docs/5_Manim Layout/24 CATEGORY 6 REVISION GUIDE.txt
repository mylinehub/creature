MOST IMPORTANT CORE REALIZATION
Bezier curves are NOT merely:
some polynomial equation
They are:
recursively repeated interpolation structures.

THE TRUE FOUNDATION
Everything started from:
(1-t)A+tB

THIS IS:
interpolation
Meaning:
move t% from A toward B

FROM INTERPOLATION TO BEZIER

LINEAR BEZIER
2 points:
P0 -------- P1
Formula:
(1-t)P_0+tP_1
This is JUST interpolation.

QUADRATIC BEZIER
3 points:
          P1
           *
          / \
         A---B
          \ /
           C
P0 *-------------* P2

PROCESS
Interpolate:
P0 ↔ P1 → A
Interpolate:
P1 ↔ P2 → B
Interpolate:
A ↔ B → C

HUGE REALIZATION
ONLY:
C
lies on actual curve.

A and B ARE:
helper interpolation points
NOT actual curve points.

MASSIVE INSIGHT
As:
t changes
A and B slide along edges.
Then C moves through evolving interpolation structure.
This moving C traces:
the Bezier curve.

HUGE RECURSIVE INSIGHT
Bezier internally contains:
smaller interpolation systems inside itself.
This became foundation of:
subdivision mathematics.

BIGGEST PROPERTY WE LEARNED
subcurve of Bezier
is itself another Bezier
THIS powers entire Category 6.
